Módulo 1: Descrição de Comunidades Biológicas — Protocolo LEGO & Análises no R

Ecologia de Comunidades: Riqueza, Abundância Relativa, Rank-Abundância e Rarefação

1 INTRODUÇÃO E CONTEXTO PEDAGÓGICO

Neste primeiro módulo prático, utilizaremos blocos de LEGO como um modelo análogo e tátil de uma comunidade biológica. Cada comunidade é representada por um saco opaco contendo 100 peças de LEGO.

1.0.1 Regra de Definição de Espécie (Módulo 1)

  • Espécie = Cor da Peça. (Exemplo: Peça Vermelha = Espécie A, Peça Amarela = Espécie B, Peça Azul = Espécie C, etc.).
  • Indivíduo = Cada peça física de LEGO.
  • Forma e tamanho: Serão ignorados neste módulo (serão utilizados como traços funcionais no Módulo 3).

2 PROTOCOLO PRÁTICO DE SALA (HANDS-ON)

2.0.1 Materiais por Grupo (4 Alunos)

  1. 1 Saco Opaco contendo 100 peças de LEGO com uma estrutura de comunidade pré-configurada.
  2. Ficha de Campo (Planilha de Amostragem Sequencial Indivíduo a Indivíduo).

2.0.2 Passo a Passo do Sorteio Peça a Peça (Individual-based Sampling)

Note🧩 PROTOCOLO DE SORTEIO PEÇA A PEÇA
  1. MISTURA: Agite suavemente o saco opaco antes de cada sorteio.
  2. RETIRADA: Sem olhar, retire 1 peça por vez (1 indivíduo).
  3. REGISTRO SEQUENCIAL: Anote a cor da peça na ordem exata de amostragem (Sorteio nº 1, 2, 3, …, 100).
  4. SEM REPOSIÇÃO: Mantenha a peça fora do saco após o registro.
  5. TABULAÇÃO FINAL: Conte o total de peças por cor e ordene da cor mais abundante para a menos abundante.
  1. Amostragem Sequencial: O sorteio peça a peça simula a caminhada no campo e o encontro sucessivo com indivíduos biológicos em um inventário.
  2. Construção da Curva Amostral do Grupo: Ao registrar a sequência exata de aparecimento de novas cores (novas espécies), o grupo constrói manualmente a sua Curva de Acúmulo de Espécies por Indivíduo.

3 EXERCÍCIO APLICADO EM R (vegan)

Nesta etapa computacional, simularemos 4 Sacos (Comunidades A, B, C e D) contendo 100 peças cada, porém com perfis de dominância e equitabilidade contrastantes:

  • Saco A (Comunidade A - Hiperdominante): Dominada por uma única cor abundante (70% das peças) e poucas espécies raras.
  • Saco B (Comunidade B - Dominância Moderada / Log-Normal): Padrão comum na natureza, com poucas espécies muito abundantes, várias intermediárias e algumas raras.
  • Saco C (Comunidade C - Alta Equitabilidade / Uniforme): Todas as espécies presentes possuem abundâncias muito similares (~10% cada).
  • Saco D (Comunidade D - Alta Riqueza com Muitas Raras / Singletons): Elevada riqueza total, com presença expressiva de espécies com apenas 1 ou 2 indivíduos (singletons e doubletons).
Code 
# Carregar pacotes necessários

3.3 3. Análise Detalhada das Curvas de Rank-Abundância (RADs / Whittaker Plots)

As Curvas de Rank-Abundância (RADs) ou Gráficos de Whittaker ordenam as espécies da mais abundante (Rank 1) para a menos abundante (Rank \(S\)), plotando a abundância relativa em escala logarítmica (\(\log_{10}\)).

3.3.1 Construção Gráfica das RADs

Code 
# Preparar dados para o ggplot2
rad_df <- matriz_lego %>%
  pivot_longer(-Comunidade, names_to = "Especie_Cor", values_to = "Abundancia") %>%
  filter(Abundancia > 0) %>%
  group_by(Comunidade) %>%
  arrange(desc(Abundancia)) %>%
  mutate(
    Rank = row_number(),
    Abundancia_Relativa = Abundancia / sum(Abundancia)
  )

# Gráfico de Rank-Abundância
ggplot(rad_df, aes(x = Rank, y = Abundancia_Relativa, color = Comunidade, group = Comunidade)) +
  geom_line(linewidth = 1.2) +
  geom_point(size = 3) +
  scale_y_log10(labels = scales::percent_format(accuracy = 0.1)) +
  labs(
    title = "Curvas de Rank-Abundância (Whittaker Plots) — Sacos de LEGO",
    subtitle = "Comparação dos perfis de dominância e equitabilidade em escala logarítmica",
    x = "Rank da Espécie (da mais para a menos abundante)",
    y = "Abundância Relativa (Escala Log10)",
    color = "Saco / Comunidade"
  ) +
  theme_minimal(base_size = 14) +
  theme(legend.position = "top")

3.4 4. Curvas de Rarefação Baseadas em Indivíduos (Individual-based Rarefaction)

A rarefação baseada em indivíduos padroniza o esforço amostral, permitindo responder: “Qual seria a riqueza de espécies esperada se tivéssemos amostrado exatamente \(N\) indivíduos em cada saco?”

3.4.1 A) Cálculo e Gráfico de Rarefação (rarecurve)

Code 
# Cores para o gráfico
cores <- c("red", "blue", "green3", "purple")

# Curvas de Rarefação para os 4 Sacos
rarecurve(mat_num, step = 1, sample = 50, col = cores, lwd = 2.5,
          xlab = "Número de Indivíduos Amostrados (Peças de LEGO)",
          ylab = "Riqueza de Espécies Esperada (E[S])",
          main = "Curvas de Rarefação Baseadas em Indivíduos (Sacos A, B, C e D)")

grid()
legend("bottomright", legend = rownames(mat_num), col = cores, lty = 1, lwd = 2.5)

3.4.2 B) Riqueza Rarefeita Padronizada (\(N = 50\) e \(N = 20\) indivíduos)

Code 
# Padronizando para N = 50 e N = 20 peças
S_rare_50 <- rarefy(mat_num, sample = 50)
S_rare_20 <- rarefy(mat_num, sample = 20)

comparativo_rarefacao <- data.frame(
  Comunidade = rownames(mat_num),
  S_Observado_100 = specnumber(mat_num),
  S_Rarefeito_50 = round(S_rare_50, 2),
  S_Rarefeito_20 = round(S_rare_20, 2)
)

print(comparativo_rarefacao)

4 QUESTÕES DE INTERPRETAÇÃO ECOLÓGICA E ESTATÍSTICA

Responda às seguintes perguntas com base nos resultados obtidos no R e na experiência do sorteio em sala:

  1. Efeito da Equitabilidade na Curva de Acúmulo: Compare o formato das curvas de rarefação do Saco A (hiperdominante) e do Saco C (uniforme). Por que o Saco C atinge a assíntota rapidamente com poucos indivíduos, enquanto o Saco A demora mais para acumular novas espécies, mesmo tendo riqueza similar?

  2. Rank-Abundância e Dominância: Na curva de Rank-Abundância (Whittaker Plot), o que a inclinação (slope) da reta representa biologicamente? Qual dos quatro sacos apresentou a maior inclinação e o que isso indica sobre a distribuição de recursos na comunidade?

  3. Padronização do Esforço Amostral: Se um pesquisador amostrasse apenas 20 indivíduos no Saco A e no Saco D, qual seria a riqueza observada em cada um? Por que a comparação direta de riqueza sem rarefação pode levar a conclusões errôneas quando o esforço ou a abundância variam?

  4. Conservação e Espécies Raras: O Saco D apresenta muitas espécies com apenas 1 ou 2 peças (singletons e doubletons). Em um ecossistema real sob perturbação ambiental, por que comunidades com o perfil do Saco D são consideradas mais vulneráveis à perda acelerada de biodiversidade?
